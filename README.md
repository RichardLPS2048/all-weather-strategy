# 全天候量化策略（All-Weather Strategy）

一个基于**风险平价 + 动量增强**的全天候量化策略，运行于聚宽（JoinQuant）平台。

**代码免费开源，但验证过程才是真正的价值所在。**

---

## 这是什么

桥水基金提出的"全天候"资产配置理念的量化实现：
- **四类资产**：股票（510300 / 159915）、黄金（518880）、债券（161716）、纳指（513100）
- **风险预算**：按 ES（Expected Shortfall，预期亏损）反比分配权重，风险越低配得越多
- **动量增强**：25 日对数回归斜率 × R² 作为动量得分，动态调整股票类资产的 ES
- **波动率调整**：短期/长期波动率比值，动态调整 ES
- **再平衡**：每 20 个周期或偏离 15% 时触发

## 真实数据（一手验证，非回测美化）

| 项目 | 数据 |
|---|---|
| 回测年化 | 约 13% |
| 回测最大回撤 | 约 5% |
| 实盘资金 | 8 万 |
| 实盘时长 | 3 个月（首月 1.6%，近 3 个月 3.1%） |
| 实盘收益 | 首月 1.6%；近 3 个月累计 3.1% |
| 实盘最大回撤 | 0.67% |
| **实盘留存率**（实盘年化 ÷ 回测年化） | **约 50%，持续跟踪中** |

> 我持续在验证"回测和实盘的差值"：差值收窄 → 回测可信；差值偏大 → 调整重测。
> 这比任何漂亮的回测曲线都诚实。详细验证过程持续更新中。
